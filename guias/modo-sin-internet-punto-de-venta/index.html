Qué debe ocurrir con tu punto de venta cuando se cae el internet

Cómo evaluar el modo sin conexión, la sincronización y los límites de pagos durante una interrupción.

EQ
Esfrailin QuezadaDesarrollador de soluciones digitales · Revisado el 17 sep 2026 · 9 min

Decir que un sistema funciona sin internet no explica qué funciones permanecen disponibles, dónde se guardan las ventas ni cómo se resuelven conflictos al volver la conexión.

1. Define las operaciones esenciales

Comprueba si puedes abrir una venta, buscar productos, aplicar impuestos, imprimir y cerrar caja. Algunas funciones secundarias pueden esperar, pero la operación principal debe estar claramente documentada.

2. Distingue venta de pago

El POS puede registrar una venta local, pero una tarjeta necesita autorización de la red salvo soluciones específicas. Explica al personal qué medios se aceptan durante la interrupción.

3. Protege las ventas locales

Los datos pendientes deben conservarse aunque la aplicación se cierre o el equipo reinicie. Realiza una prueba controlada sin conexión y verifica que las ventas reaparezcan.

4. Revisa la sincronización

Cuando vuelve internet, el sistema debe enviar cada operación una sola vez y reportar errores. Prueba cambios simultáneos de inventario para conocer cómo resuelve diferencias.

5. Crea un procedimiento

Mantén teléfonos de soporte, medios de pago alternativos y pasos para reconectar. Registra hora de inicio y final de la interrupción para conciliar los resultados.

Lista de comprobación

  • Ventas básicas funcionan sin conexión
  • Datos sobreviven a un reinicio
  • Pagos disponibles están definidos
  • Sincronización no duplica operaciones
  • Personal conoce el procedimiento
Nota editorial

Esta guía es educativa e independiente. Las recomendaciones se basan en criterios técnicos y operativos; no en pagos por posicionamiento.
