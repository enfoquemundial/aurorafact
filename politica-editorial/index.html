Política editorial

Criterios que utilizamos para investigar, redactar, actualizar y corregir el contenido.

Contenido original

Las guías se escriben para responder preguntas reales. Priorizamos pruebas propias, documentación oficial y fuentes primarias. No copiamos artículos ni reescribimos noticias para aumentar el volumen.

Independencia

Las decisiones editoriales no dependen de pagos. Si en el futuro un contenido incluye enlaces comerciales o patrocinio, se identificará de forma visible antes de la recomendación.

Revisión y actualización

Cada página muestra su fecha de revisión. Actualizamos pasos, compatibilidad y referencias cuando cambian los productos o servicios tratados.

Correcciones

Corregimos errores factuales con rapidez. Cuando la corrección cambia la conclusión de una guía, añadimos una nota explicando qué se modificó.

Uso responsable de herramientas

Podemos utilizar software para organizar investigación o revisar redacción, pero una persona responsable revisa y aprueba el contenido publicado.
